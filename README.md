# README Quick Check

Local-first README quality checker.

## Features

- No signup
- No tracking
- No server calls
- Static HTML only
- Checks install, usage, configuration, tests, license, and contribution notes

## Usage

Open `index.html` in a browser, paste README text, and run the check.

Live demo: https://alex-parejo.github.io/readme-quick-check/
