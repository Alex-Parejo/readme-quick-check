## Fix Note

The README explains what the tool does, but it does not give a first-time visitor a copyable path from "I found this" to "I can try it now." Add a short quickstart block before the feature list so visitors see the fastest successful action first.

## Copy-Ready Snippet

```md
## Quickstart

Open the live demo:

https://alex-parejo.github.io/readme-quick-check/

Paste your README text, click **Check README**, and review the missing onboarding sections. The check runs locally in your browser; no README content is sent to a server.
```

## Why This Helps

- Reduces uncertainty for first-time users.
- Makes the live demo the primary action.
- Reinforces the privacy benefit at the exact moment users paste content.
